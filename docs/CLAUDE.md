## Project Overview

Research project on using Variational Autoencoders (VAEs) for time series compression of data generated by the generalized Lotka-Volterra (GLV) model. Inspired by https://github.com/yasab27/LSMGD.

The core idea is to compress multivariate ecological time series (7 species × 129 timesteps) into a low-dimensional latent space and reconstruct them accurately.

## Architecture Overview

### Model Types

Multiple VAE architectures are implemented in `VAE/models/`:

- **VAE.py**: Convolutional VAE (baseline) - uses Conv1d encoder/decoder
- **RNN.py**: RecurrentVAE - LSTM-based encoder/decoder with teacher forcing
- **CH_VAE.py**: Channel-based VAE architecture
- **MLP_VAE.py**: Fully-connected VAE
- **attention.py**: Memory-efficient VAE with attention mechanisms
- **KAN.py** / **CompleteKAN.py**: Kolmogorov-Arnold Network based VAEs
- **cvae.py**: Conditional VAE variant

All models follow the same interface:
- Input: `(batch_size, in_channels, seq_len)` → `(N, 7, 129)`
- Output: `X_hat, code, mu, log_var` where code is the latent representation

### Training Pipeline

**Entry point**: `run.py` - selects model architecture and calls `train()`

**Training loop**: `train.py` contains:
- `train()`: Main training loop with W&B logging, beta warmup, AMP for performance
- `test()`: Evaluation function computing reconstruction loss, KL divergence, and 2σ coverage metrics
- `inference()`: Visualizes reconstruction quality on fixed test samples
- `generate_and_log_curves()`: Samples from latent prior to generate new time series

**Loss function**: `utils/loss.py` - `alpha_div_loss()` implements alpha-divergence reconstruction loss with beta-weighted KL divergence

**Configuration**: `config.py` defines:
- `hp`: Training hyperparameters (lr, epochs, batch_size, beta scheduling)
- `model_config`: Architecture hyperparameters (latent_dim, channels, depth)
- `DEVICE`: cuda/cpu selection

### Data Generation

Located in `data_generation/`:

- **glv_functions.py**: Core GLV dynamics implementation
  - `dynamics_LV()` / `custom_dynamics_LV()`: Runge-Kutta solver for GLV equations
  - `elliptic_normal_matrix()` / `uniform_normal_matrix()`: Generate interaction matrices
  - `zero_LCP()`: Solve Linear Complementarity Problem for fixed points
  - `empirical_prop()`: Monte Carlo estimation of ecosystem properties

- **generate_family.py**: Generates datasets of GLV time series families
- **custom_glv.py**: Custom GLV parameter configurations

**Data format**: Pickled numpy arrays in `data/` with shape `(N_families, n_species, n_timesteps)`
- Each "family" shares an interaction matrix but has different initial conditions
- Normalization: Min-max per family to [0,1] range

## Key Implementation Details

### Beta Warmup Strategy
KL divergence weight (`beta`) linearly increases from 0 to `beta_max` over first 30% of training to prevent posterior collapse.

### Alpha-Divergence Loss
Uses generalized alpha-divergence for reconstruction instead of standard MSE:
```
L_i = (1/alpha) * log(mean(exp(-alpha * 0.5 * MSE)))
```
This provides more robust density estimation than plain MSE.

### Recurrent VAE Specifics (RNN.py)
- Encoder: Bidirectional LSTM → flatten hidden states → bottleneck
- Decoder: Latent code initializes LSTM hidden/cell states → teacher forcing during training
- For generation: Autoregressive sampling (model uses own outputs as next inputs)

### Model Evaluation Metrics
- **Reconstruction Loss**: Alpha-divergence between input and reconstruction
- **KL Loss**: Divergence from unit Gaussian prior
- **Coverage**: % of ground truth points within mean ± 2σ of stochastic reconstructions
- Per-channel coverage tracked separately for each of 7 species

### Automatic Mixed Precision
Training uses `torch.cuda.amp` for faster training on compatible GPUs. Scaler handles gradient scaling automatically.

## Important Notes

- **Device**: Hardcoded to 'cuda' in config.py - change if running on CPU
- **Wandb**: Logging enabled by default (LOG=True in train.py). Disable for faster iteration
- **Random Seeds**: Set in run.py (torch) and train.py (numpy) for reproducibility
- **Data Loading**: Uses pickle files - ensure data/ directory contains required .pkl files
- **Teacher Forcing**: RNN decoder uses ground truth during training but autoregressive generation during sampling
